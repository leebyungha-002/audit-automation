# FSS 감사 참고자료 앱

## 실행
- 화면: `streamlit run app.py` (app.py) / 터미널: main.py

## 목적
금감원 회계업무자료 Open API를 수집해 로컬 DB에 쌓고, 감사 중 키워드로 검색한다.

## 확인된 사양 (금감원 안내문 2쪽)
- 주석공시 모범사례: https://www.fss.or.kr/fss/kr/openApi/api/illustDisc.jsp
- 요청변수: apiType(xml|json), startDate, endDate(YYYY-MM-DD), authKey
- JSON 최상위 키는 `reponse` (오타 그대로. `response`도 허용할 것)
- reponse.resultCode "1" = 성공, resultCnt, result[]
- 항목: contentId, subject, contentKor, regDate, originUrl, atchfileUrl, atchfileNm
- contentKor는 HTML이 이스케이프되어 온다

## 홈페이지 '상세 및 테스트'에서 확인 (2026-11-28, 실제 키 호출 검증 전)
- 요청URL은 모두 `https://www.fss.or.kr/fss/kr/openApi/api/{이름}.jsp`, 요청변수는 주석공시와 동일
- kifrsQa(K-IFRS 질의회신, +relStand), kgaapQa(일반기준 질의회신), icfrData(내부회계관리제도),
  inspExmpl(심사·감리지적사례, +rlsNo/issRealm/relStand/dcsnYr/sprvisnTrgtYr/deptNm),
  audData(외부감사 업무자료), audFaq(외부감사 FAQ)
- 홈페이지 결과변수 표기는 `contentsKor` (안내문은 `contentKor`) → 둘 다 허용
- 수집 실패 시 해당 API만 건너뛰고 나머지는 계속 수집한다

## 미확인 (추측 금지)
- 위 6개 API의 실제 응답 (키 발급 후 `python main.py sync 2026 2026`으로 확인)
- 호출 한도, 최대 조회기간, 페이지 처리, 오류코드

## 규칙
- 인증키는 .env에만 둔다. .env를 읽거나 출력하지 않는다.
- 로그와 예외 메시지에 요청 URL(authKey 포함)을 남기지 않는다.
- 고객사 데이터는 이 저장소에 넣지 않는다.
- 첨부파일(attach.py)은 금감원 https 주소만 허용하고, 기존 버전을 덮어쓰지 않는다.
- 원본 응답 항목과 수집일시를 보존한다. 내용이 바뀌면 이전 버전을 지우지 않는다.
- 변경 후 `python -m pytest` 실행.

## 범위 제외
- 시산표 계정과목과 지적사례 키워드를 연결하는 계정별 위험 점검표는 만들지 않는다. 이미 다른 앱으로 개발되어 있다.
