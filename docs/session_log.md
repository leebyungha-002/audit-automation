## 2026-08-13 (9차) — 계산 로직 전면 재설계

**배경**: 사용자가 "취득정보를 기초취득원가/당기취득원가/당기처분원가로 구성해달라"고 요청 → 논의 중 "감가상각누계액·손상차손누계액·정부보조금도 같은 로직으로" 확장 요청받음. AskUserQuestion으로 핵심 갈림길(기초 감가상각누계액을 취득일부터 재시뮬레이션할지, 회사계상 전기말값을 그대로 신뢰할지) 확인 → **회사계상 전기말값을 그대로 신뢰하는 방식**으로 확정

**설계 전면 변경**: 취득원가·감가상각누계액·손상차손누계액·정부보조금잔액 4가지 전부 동일한 패턴으로 통일
- **기초잔액은 전부 직접 입력**(회사 보고값 그대로 신뢰) — 더 이상 취득일부터 다년간 이력을 시뮬레이션하지 않음
- **당기 증감만 앱이 계산**: 당기감가상각비/당기손상차손인식액(이벤트)/당기정부보조금환입액(비율계산)
- **기말잔액 = 기초+당기증가-당기감소** (계산)
- 이 원칙 덕분에 기존에 있던 "전기말 회사계상 감가상각누계액" 등 대사용 필드와 "기초누계액 차이" 컬럼이 사라짐(기초값 자체가 이미 회사계상값이므로 차이 개념이 없어짐) — 오히려 컬럼이 단순해짐

- 기존자산(기초취득원가>0): 기초 감가상각누계액/손상차손누계액/정부보조금잔액을 입력값 그대로 사용. 취득일이 있으면 그걸로 "잔여내용연수(개월)"를 계산(정액법 상각률 산정용), 없으면 내용연수 전체를 근사치로 사용
- 신규취득자산(당기취득원가>0): 취득일 필수, 기초잔액 전부 0에서 시작
